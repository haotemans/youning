# 云团专属表情包 v1

四张用户提供的 Gemini 拼图原件保持不变，来源文件名及每格文字记录在 `manifest.json`。每张为 2048×2048 的 4×4 网格，共 64 格、60 个标签。重复标签保留不同画面。

程序首次启动时从每个 512×512 单元四周各避开 4 像素分隔线，输出 504×504 PNG，按图中文字语义分类并启用。只提取像素，不重绘、不改字、不缩放。这批人工确认的素材只做精确哈希去重，避免相似角色与构图使不同文字被感知去重丢弃；普通采集素材仍使用原有去重规则。

导入完成后记录 `meme_pack:cloud:v1`，后续启动不覆盖管理员的删除、停用和分类调整。资料随二进制携带，部署不依赖开发机器的下载目录。

Windows 下可运行 `scripts/export-cloud-memes.ps1` 导出相同网格切片供预览或手动使用。运行时自动导入使用 Rust `image` 库，不依赖 Windows 或该脚本。
