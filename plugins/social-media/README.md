# 采薇

视频与图文解析下载（实验性）。名字出自《诗经·小雅·采薇》“采薇采薇，薇亦作止。”，插件 ID 仍为 `social-media`。

纯 Rust 编译期插件，支持 B站、抖音、小红书、X 的公开分享链接解析规则，视频与图文共用流式下载器。平台规则和可见性变化会影响成功率，不保证任意链接可下载。

## 当前实测状态（2026-10-14）

- X：2026-10-11 公开帖子 `https://twitter.com/CTVJLaidlaw/status/1600649710662213632/video/1` 实际解析并下载两个 MP4，总计 31,217,419 字节；2026-10-14 重测该样例请求失败或超时，当前连通性未通过。另一个旧样例无媒体，正确报错。
- B站：已实现 BV/av、分P和动态图片解析；本机公开样例 `BV1GJ411x7h7` 完整下载 MP4，10,516,124 字节。`BV1xx411c7mD` 解析成功，下载因超出默认单文件 50 MiB 限制而正确中止。此前出现过 HTTP 412，仍可能受平台限制。
- 抖音：分享页 hydration 数据解析及图集处理通过固定数据测试；旧公开样例未返回作品，等待实际链接验收。

- 图片/视频发送使用模拟适配器测试，未在真实 QQ 群发送测试文件。

## 使用

默认编译进云团，但首次默认关闭。插件面板启用“解析视频下载”，设置文件上限和会话范围，配置即时生效。默认自动识别群聊中的支持平台分享链接（包括小红书 `xhslink.com`、`xhslink.cn`），无需命令、@机器人或 Decision 模型，每条分享消息直接进入处理队列，不参与聊天聚合。面板可关闭自动解析。聊天中明确要求下载时，Decision 也可调用同名 Skill；此路径需要 Decision 模型。Agent 工具返回结构化结果和附件路径，写入任务记录；Agent 任务本身遵循现有不自动发群规则。

直接命令：`/下载 <分享链接>` 或 `/download <分享链接>`，不依赖 Decision 或 BotChat 模型。命令必须位于消息开头，并与链接以空格分隔；插件启用状态、会话范围、超时和并发限制照常生效。抖音和小红书严格匹配目标作品 ID，缺少目标作品时报告失败，避免下载页面推荐的其他作品。

本插件不提供面板上传安装，也不依赖收费解析 API、Python 或 yt-dlp。资料只用于参考公开页面结构和测试样例，实际运行代码是 Rust。

## 支持范围

- B站 BV/av 视频及指定分P；动态中的图片。请求平台提供带音轨的 MP4，暂不合并 DASH 分离音视频、不拼接分段，多个可用 MP4 分别交付。
- B站视频信息接口返回 HTTP 412 时，只回退一次到官方分P接口，保持原 BV/av 和所选分P；回退时以分P名称作为标题。b23 短链取得可识别的视频/动态地址后不再额外请求落地网页。若分P或播放接口也受限，仍可能需要在采薇设置中配置 `bilibili_cookie`，不保证所有服务器出口可用。
- 抖音长链接、短分享链接、图文作品，读取公开分享页作品数据。
- 小红书 explore / discovery/item、短分享链接；保留原链接中的 xsec_token，读取对应笔记。不要把验证页中的推荐内容当成目标笔记。
- X / Twitter status 及 t.co 链接；读取公开 syndication 数据，选择每个视频最高码率 MP4、保留帖子全部图片/视频。公开嵌入接口可能不提供某些媒体。当前不支持私密或受限帖的登录下载。
- 不破解登录、验证码、付费限制或 DRM。遇到受限内容给出失败原因。

Cookie 在面板按站点可选配置，读取接口不会返回值。仅发送给对应站点域名，CDN 请求不继承 Cookie。不要将 Cookie 写入文档或聊天。

## 下载与交付

默认单文件 50 MiB、单次合计 100 MiB、最多 20 个文件、并发 1、调用超时 120 秒。下载逐块写入磁盘，不在内存保留完整视频；响应体超过配置上限立即停止。页面 JSON 上限 8 MiB。校验媒体文件头，验证页等非媒体响应不能标记为下载成功。

文件写入宿主的 `data/plugins/social-media/artifacts/`。下载失败或取消时删除该次下载的中间文件。聊天中的视频和图文附件收到发送成功回执（含消息 ID）后，自动删除对应本地临时文件；发送失败、仍在重试、回执不完整或尚未发送时保留。每个附件独立清理，一组附件部分发送失败不会删除失败文件。Agent 或命令行仅下载未发送的文件仍保留。宿主检查附件路径属于本插件，不允许返回任意本机文件。

下载成功后，结果整体进入群内串行发送队列，默认先尝试撤回触发下载的原消息，再发送结果；下载失败或附件丢失时不撤回。目标仅来自当前群已记录的触发消息，不接受模型指定任意消息 ID。机器人须具有管理员权限，且原作者为普通成员；撤回失败时保留原消息并继续交付，在事件中记录原因。面板可关闭撤回。重启不回放插件触发消息，防止重复下载和撤回。

默认 1–3 个附件按顺序直接发送，达到 4 个时把作品说明和图片/视频折叠成一条合并聊天记录，面板可调整阈值为 1–30。私聊命令支持合并发送，但不自动撤回。折叠发送成功且回执包含消息 ID 后清理整批临时文件；重试、失败或缺少 ID 时保留全部文件，不退回逐条刷屏。下载完成说明表示开始交付，不代表 QQ 已接收；实际结果与清理结果由适配器回执写入事件。清理只针对本插件输出文件，不扫描历史目录。NapCat 与云团须能访问同一文件路径（跨机器部署需文件上传通道），大文件还受 QQ/NapCat 自身限制。

仓库 Compose 将本插件与 NAI 的 `artifacts` 输出目录按相同绝对路径只读挂载到 NapCat，供 `file:///` 附件读取；修改挂载后须重建 NapCat 容器。插件配置与密钥文件不在这些共享目录中。

默认启用 Fake-IP 兼容：仅当系统 DNS 全部返回 198.18.0.0/15 或 2001:2::/48 基准测试地址时，通过 Cloudflare `https://1.1.1.1/dns-query` 查询公共 A 记录；可在面板关闭。所有目标和每次重定向仍校验公共 IP 并固定解析结果，拒绝内网/回环/链路本地地址，不继承系统 HTTP 代理。

## 开发验证

```text
cargo test -p yuantuan-plugin-social-media
cargo test -p yuantuan-core --test plugin_host --test plugin_attachments
cargo run -p yuantuan-plugin-social-media --example inspect -- <分享链接>
cargo run -p yuantuan-plugin-social-media --example download -- <分享链接>
```

inspect 只解析、不下载；download 写入临时目录并打印输出路径，不发送到 QQ。
