# 敬之

群聊管理。名字出自《诗经·周颂·敬之》“敬之敬之，天维显思。”，插件 ID 仍为 `moderator`。

纯 Rust 群管理插件，默认编译并启用。支持撤回、禁言和解除禁言，直接命令无需配置模型。

在插件管理页点击“敬之”，可以配置允许操作的管理员 QQ 和单次禁言上限。操作员列表用逗号分隔；留空允许当前群的全部群主和管理员。该列表只收紧权限，不会赋予普通群成员管理员权限。保存后自动应用，插件会话范围仍由宿主的 `allowed_chats` 设置控制。

## 命令

- `/禁言 123456789 10`：禁言该成员 10 分钟，也支持 `10分钟`。
- `/禁言 @成员 10`：只选择一个目标成员；机器人自身的 @ 不计入目标。
- `/解除禁言 123456789` 或 `/解除禁言 @成员`。
- 引用目标消息后发送 `/撤回`；也可 `/撤回 OneBot消息ID`，支持负数消息 ID。

自然语言可通过 Decision 选择 `moderator.ban`、`moderator.unban`、`moderator.recall`。工具接收 `user_id`、`duration_minutes` 或 `message_id`，不接受任意群号。任务调用也受相同群权限检查。

## 权限与结果

每次操作从 NapCat 实时查询操作员、机器人和目标成员角色，不使用模型提供的角色。操作员必须是当前群群主或管理员；管理其他成员时机器人也须拥有管理员权限。不能禁言机器人，不能管理群主或管理员的消息和禁言状态；机器人撤回自己的消息无需机器人管理员权限，但操作员权限仍须核验。

撤回只允许当前群中云团已记录的 OneBot 消息 ID，不使用数据库行号，不允许跨群撤回。未连接 NapCat、角色查询失败、权限不足、回执超时或接口拒绝均报告失败；收到成功回执后才返回完成说明。动作不自动重试，避免超时后重复执行。

默认单次禁言上限 1440 分钟，面板可设为 1–43200 分钟；解除禁言发送 duration=0。宿主默认调用超时 60 秒、并发 1。QQ 本身的撤回时间限制和管理权限仍由 NapCat/QQ 执行。

## 验证

```text
cargo test -p yuantuan-plugin-moderator
cargo test -p yuantuan-adapter-qq --lib moderation
cargo test -p yuantuan-core --lib plugin_command
cargo test -p yuantuan-core --test plugin_host
```

测试覆盖命令解析、引用与 @ 目标、时长上限、操作员限制、实时角色检查、跨群撤回、机器人权限和失败回执。使用本地模拟接口，没有向真实 QQ 群执行禁言或撤回。
