# 关系图谱渲染优化

- 图谱请求独立于仪表盘；等待 Vue 更新画布容器尺寸后再初始化 Network，离开页面时取消请求并销毁实例。
- 使用预设分散坐标立即显示图谱，关闭阻塞首帧的 improved layout 和隐藏稳定计算；可见物理布局最多运行 1.5 秒，减少动态效果时直接使用静态布局。
- 节点先显示本地头像，远程头像以 4 个加载任务逐步补全，每个任务最多等待 4 秒；头像服务不可用时保留本地头像。
- 简化连线，拖动画布时隐藏边；人物搜索支持过滤并聚焦节点，提供加载、空数据、错误和重试状态。
- 新增浏览器回归测试：159 节点/247 关系、慢仪表盘与头像、头像成功补全、失败重试、空数据、加载中离开页面，以及窄屏下 1000 个孤立节点。通过 `npm run test:relations` 执行，已加入 GitHub Actions。

原页面在本地模拟的 159 节点数据下能显示，尚未复现生产截图中的持续空白；以上修改消除了已识别的阻塞路径，并补充可见错误与回归覆盖。生产环境仍需部署后核验。

后续生产错误 `URI malformed` 已用 emoji 昵称复现：占位头像通过 `charAt(0)` 截取昵称，拆断 UTF-16 代理对，导致 SVG 的 `encodeURIComponent` 抛错。改为按 Unicode 码点截取，并替换原数据中孤立的代理码元；新增 emoji、生僻字、损坏代理码元和 XML 特殊字符的浏览器回归用例。
