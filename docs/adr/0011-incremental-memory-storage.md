# 用增量批次和版本记录保存可追溯记忆

Status: accepted

2026-11-06，用户要求参考腾讯开源记忆 Agent，并结合现有记忆系统优化存放。本决定补充[ADR-0008](0008-grounded-bot-context.md)，修订Q9的“只取最近500条”抽样方式，保留一人一份档案、原话归属与固定回复快照。

参考 [TencentDB Agent Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory) 的原始对话、事实、场景记忆和人物资料分层。云团继续使用 Rust、SQLx 和本地 SQLite，在现有表旁追加证据事实、会话日记、画像历史及批次进度；现有当前画像、长期记忆和旧摘要保持兼容。各层通过原消息编号和批次关联，提炼结论不等于独立验证事实真实性。

归纳按会话类型与编号处理连续消息前缀，成功结果与游标同事务提交；模型失败、取消和迟到回调不能把未处理输入标成完成。熟悉度统计使用独立SQL游标，保留无模型可用时的统计能力并防止重试重复累计。升级时保留旧数据并记录基线，不为旧无出处材料补造证明，也不自动重提炼全部旧聊天。

当前画像仍是少量可用字段，版本日志用于追溯修正和还原已有历史范围内的回复资料；现存旧画像只能导入为初始版本。会话日记保留实际日期、参与者归属和来源范围，同一人物来自多个群或私聊的记录互不覆盖。画像来源仍是本人原话，不从日记递归生成性格，也不凭图片观察确认现实身份或关系。

沿用北京时间03:00串行夜间调度、每晚最多10人的画像额度和60秒间隔；源数据不会因本晚预算用尽而被清理。暂不增加向量服务、外部记忆容器或每条消息模型提炼。完整业务契约、表映射、UI与验证入口统一维护于[记忆功能文档](../features/core/memory.md)，避免与本ADR重复维护。

`accepted` 记录设计选择；实现状态、mock/API/浏览器验证与生产部署分别记录，不能以设计或编译成功替代真实模型与服务验收。
