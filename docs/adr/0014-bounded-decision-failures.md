# ADR-0014：无动作判断与有界失败

日期：2026-11-08。状态：accepted。修订ADR-0013的无限重排、无动作也选目标及旧消息自动回应策略。

## 原因

生产记录出现模型路由HTTP400后消息累计失败11次仍等待重试；更换模型后，纯ignore因缺少target_msg_id仍频繁补调。成功构建和协议替身不足以证明真实模型遵守所有无关输出字段。

## 决定

- 周期批次的纯ignore没有记忆、任务控制或技能副作用时，允许省略目标及无关输出字段，一次调用即可结束。缺少mood不改当前情绪，没有目标不伪造作者。任何回应或副作用仍须真实本批目标、严格Schema及既有权限校验。
- 一条消息累计失败最多3次，首次失败后最多重试两次，间隔30、60秒；重启不清零。待处理超过10分钟停止自动补答，原文仍供记忆与历史查询。
- HTTP400/401/403/404/405/410/422等确定性错误立即停止该消息，当前Decision网关暂停后续上游请求；模型配置重载创建新网关后解除，不改用户模型。429、5xx、网络和Schema失败只做有界重试。
- 队列容量不足只释放领取，不增加模型失败次数。已经成功读取但让位给新定向对话的主动回应结束该批，不作为失败重排。
- V14追加decision_error，failed、uncertain、done明确区分。界面显示停止原因与当前配置错误，没有盲目重放入口。

## 验证边界

回归覆盖无目标纯忽略一轮完成、副作用目标约束、永久错误不重复HTTP、配置重载恢复新消息、失败限额跨重启、过期保留原文和页面停止状态。真实模型验证只观察自然会话和已有运行记录，不用主动群发作为部署探针。当前行为以[会话调度](../features/core/conversation.md)、[参与判断](../features/core/decision.md)及[模型配置](../features/webui/models.md)为准。
