# 云团专属表情与聊天配图

Status: accepted

2026-11-08：生产库中60张云团表情均存在，但模型只看到分类名，不知道图包归属；纯图片发送没有原请求锚点且历史只有“图片”，导致“你自己的呢”被澄清或写成虚构生图动作。用户同时要求提高日常聊天的表情参与。

保留SQLite现有图库、分类及管理员状态，用内置cloud-v1标记区分专属与其他图库，并在上下文提供已发语境。默认优先云团，明确图包严格筛选，缺货不串图或使用NAI替代。Decision允许reply附图，Chat指令继续可用；每回复至多一图，库存请求不能派工或请求生图。

频率由实际发送而非模型决策次数衡量：普通配图至少间隔30秒，近5分钟至多4张，连续2轮文字后提示考虑合适配图；语义仍决定是否适合，不强制随机发图。明确请求用原话、对象和意图确认后独立放行。参数为初始代码策略，未新增运行参数控件。

成功发送后保存图包/类别及原reply_anchor_id，内部身份不发给QQ群；失败或未知不写成成功，旧未知图片不猜测回填。无需新增表或迁移。图库UI提供图包筛选，Trace区分计划与回执。

本决定补充ADR-0015的社交接话与ADR-0016的真实来源约束，不放宽生图、工具或Agent授权。mock、API与浏览器回归验证路由及送达记录；真实模型选择质量与真实QQ交付另行验证。完整契约集中在[表情功能](../features/core/memes.md)。
