# ADR-0012：上下文、可追溯记忆与可恢复任务

日期：2026-11-07。状态：accepted，实施边界以功能文档和测试为准。

保留Decision/bot_chat/agent_exec，沿用回复快照与V11增量存储。30天是按需检索范围，人物身份跨会话统一，私聊来源不能流入群上下文。新增语义条目保留版本、依据和有效状态；原始记录及群历史不删。

默认2个任务执行槽；任务独立于执行器，子任务共享根预算。调用前记录、结果与检查点原子提交；未知副作用不自动重放。Router分配预算，运行时执行硬上限与无进展检查。任务结果与消息送达分开，持久outbox恢复可发送正文。

参考取舍：腾讯Agent-Memory的来源/事实/综合分层，以及SuperAgent研究原型的事件、任务、执行器和outbox分离；不引入外部服务，不将研究设计当成生产保证。

尚未完成的设计项：精确tokenizer和模型能力目录、跨夜长期话题的语义合并评估、未知动作人工核实后的恢复界面。当前功能不宣称这些已经实现。

材料缓存采用SQLite触发器世代+可见范围/版本键；任务阶段压缩保留原目标、回执和最近工作记录。Agent正文与当前版本产物合并投递，失败产物保留供核实。

2026-11-13：后续Chat/Router/Agent边界、工作记忆、通用工具协议与Docker闭环由 [ADR-0018](0018-lightweight-agent-runtime.md) 细化。该设计待实现，不能据其接受状态推断本页现有实现已升级。
